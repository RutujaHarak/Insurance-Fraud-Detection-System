About the Project

Insurance Fraud Detection System


The Insurance Fraud Detection System is a Machine Learning-based web application developed to identify potentially fraudulent insurance claims. It analyzes important claim information and predicts whether a claim is likely to be genuine or fraudulent using a trained Random Forest Classifier.

The system provides a fraud prediction, confidence score, risk level, and recommendation to support faster and more informed claim verification.


Key Features

  • Machine Learning Based Fraud Detection
  • Interactive Dashboard with Analytics
  • Instant Claim Prediction
  • Confidence Score
  • Risk Level Analysis
  • Risk-Based Recommendation
